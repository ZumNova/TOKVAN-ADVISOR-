# Bitácora ERC-3643 · Sepolia educativo

Pendiente del primer despliegue público firmado por el usuario. Las pruebas automatizadas son locales y no generan direcciones públicas válidas para Sepolia.

Guardar desde la web:

1. Hash y dirección de Token, IdentityRegistry, IdentityRegistryStorage, ClaimTopicsRegistry y TrustedIssuersRegistry (implementaciones oficiales reutilizables).
2. Hash y dirección del factory educativo.
3. Nombre, dirección y hash de creación de cada token; hash del expediente ficticio; direcciones de sus módulos.
4. Acreditaciones y revocaciones ficticias, transferencias, congelamientos, quema y recuperación.

En Bitácora ERC-3643, Actualizar después de dos bloques y Descargar JSON. Para administrar un token anterior, Usar para recuperar junto a su nombre. El expediente completo se descarga por separado: la blockchain conserva solo su hash.
