# Bitácora ERC-1155 · Sepolia

Estado: implementación preparada; pendiente del primer despliegue público firmado desde la wallet A047. No se han registrado direcciones o hashes públicos ERC-1155 todavía.

La bitácora operativa está en Factory → ERC-1155 → Bitácora ERC-1155. Actualizar después de dos bloques y descargar su JSON. Allí se muestran nombre de colección, contrato, hash de creación y botón Usar para recuperar. El hash del factory tiene su propia entrada y botón para copiar.

Registrar al realizar la prueba pública:

- Factory: dirección, hash y bloque de despliegue.
- Colección: nombre, dirección, expediente y hash de creación.
- Tipo: ID, nombre, URI del JSON, cantidad inicial, máximo histórico y hash de emisión.
- Transferencias, quema parcial, pausa y reanudación: hash y resultado confirmado.

El flujo y los participantes se describen en [ERC1155_FACTORY.md](ERC1155_FACTORY.md). Las pruebas locales no constituyen despliegues públicos en Sepolia.
